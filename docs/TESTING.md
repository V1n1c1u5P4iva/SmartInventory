# Checklist de testes manuais

Execute `.\gradlew.bat runClient` e verifique:

- [ ] O cliente inicia sem erros relacionados ao mod.
- [ ] J abre o painel principal.
- [ ] H alterna o HUD de ocupação.
- [ ] K abre a tela de configurações do HUD.
- [ ] B cancela uma organização em andamento.
- [ ] A organização alfabética mantém os itens esperados.
- [ ] A compactação combina pilhas compatíveis.
- [ ] Slots favoritos permanecem protegidos.
- [ ] A prévia mostra as alterações antes da confirmação.
- [ ] A análise de itens repetidos exibe resultados.
- [ ] Alterações de configuração e favoritos são salvas e recarregadas.
- [ ] Os indicadores de ocupação são atualizados.

Os testes acima exigem execução dentro do Minecraft; a compilação não os
substitui.
